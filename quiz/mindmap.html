의제설정
사회문제가 정책의제가 되는 과정
▶
정책의제 개념 — 계층 구조
공중의제 3조건설정과정 유형
▶
  • 사회문제 — 불특정 다수에게 결함·불만을 야기하는 상황
  • 사회적 쟁점 — 집단 간 견해차가 있어 논쟁이 되는 문제
  • 공중의제 — 대중 주목 + 정부 개입 정당하다고 인정
    • ① 많은 사람이 관심을 가져야 함
    • ② 정부 조치가 필요하다고 상당수가 의식
    • ③ 해결이 정부 권한에 속한다고 다수가 믿어야 함
  • 정책문제 — 정부가 해결 필요성 인식·공식 대처 결정
  • 정책의제 (최상위) — 정책적 해결을 의도하여 공식 채택된 문제
  • 설정과정 경로
    • 사회문제 → 쟁점 → 정책의제 (제기 집단 힘이 강할 때)
    • 사회문제 → 쟁점 → 공중의제 → 정책의제 (공감대 확산)
    • 사회문제 → 정책의제 (정책담당자 주도 / 후진국형)
킹던의 다중흐름모형
3흐름 결합정책의 창
▶
  • 문제의 흐름 — "이게 문제인가?" 인식 과정
  • 정책의 흐름 — "해법이 있는가?" 대안 준비 과정
  • 정치의 흐름 — 여론 변화·정권교체·이익집단 압력 (가장 큰 영향, 나머지 두 흐름과 독립)
  • 정책의 창 — 3흐름이 결합(coupling)할 때 의제화 가능
    • 열리는 트리거: 특정 사고·위기·재난 / 선거·정권교체
    • 닫히는 요인: 문제 해결 인식, 창 사건 소멸, 주요 인사 이동, 대안 부재, 흐름 미결합
  • 비권력 집단도 약한 흐름을 강화해 정책 주도 가능 → 간호계 참여 전략 근거
무의사결정론
Bachrach & Baratz권력의 두 얼굴
▶
  • 핵심 주장 — 의제설정은 특정 엘리트·정치집단이 조정·통제함
  • 무의사결정 — 의사결정자의 가치에 도전하는 주장을 억압·좌절시키기 위한 결정
  • 수단 5가지
    • ① 폭력 행사
    • ② 가치박탈·위협·회유 등 권력행사
    • ③ 편견의 동원 — 주장을 "비애국적·비논리적"으로 낙인
    • ④ 편견을 수정·강화하는 우회적 전략
    • ⑤ 지연전략
  • 의제에 오른 것뿐 아니라 오르지 못한 것도 분석해야 함
정책의제 영향요인
Cobb & Elder 5가지촉발기제
▶
  • Cobb & Elder — 문제의 성격 5가지
    • ① 구체성
    • ② 사회적 유의성
    • ③ 시간적 적시성
    • ④ 선례의 유무
    • ⑤ 기술적 복잡성
  • Hogwood & Gunn — 7가지 위기의 정도 / 특수성 / 감정적 측면 / 영향의 범위 / 유행성 / 권력과 정통성 / 주도집단
  • 주도집단
    • Gate-keeper: 지도자·정책결정자의 관심
    • 정책선도자: NGO·시민단체·언론·이익집단 (정부 외부)
    • 대중매체: 집중적 관심 → 의제화 가능성 ↑
  • 정치적 요소 — 체제 구조, 이데올로기, 정치체제 능력
  • 촉발기제(Triggering Mechanism) — 사건·위기·재난이 점화장치 역할
    • 영향력 = 집단 규모 × 사건 심각성 인식 수준
    • 배분정책: 문지기 관계 중요 / 규제정책: 의제화 어려움
미디어 프레이밍
의제설정 vs 프레이밍리터러시 4요소
▶
  • 의제설정 "What to think about" — 무엇을 중요하게 다루느냐
  • 프레이밍 "How to think about it" — 이슈를 어떻게 해석할 것인가
  • 프레이밍 4가지 작동 방식
    • 선택(Selection): 특정 사실만 기사화
    • 강조(Emphasis): 헤드라인·사진으로 특정 관점 강화
    • 배제(Exclusion): 프레임 밖 정보 생략
    • 맥락화(Context): 배경 부여로 특정 결론 유도
  • 미디어 리터러시 4요소 — 접근·분석·평가·생산
  • 소셜미디어 리터러시 — 방향: 다방향 / 판단기준: 서사 일관성·정서적 공명도 (기존과 별도 함양 필요)
  • 미디어 옹호자 — 소비 → 생비자 → 전략적 미디어 활용 (대중교육 → 문제 프레이밍 → 전문가 개입 촉발)

정책결정
대안 개발·평가·선택의 과정
▶
정책결정 개념과 유형
5가지 특성vs 의사결정
▶
  • 정책결정 5가지 특성
    • ① 강제력과 정통성 — 주체는 정부·공공기관
    • ② 공익 — 사익 추구 기업 정책과 구별
    • ③ 관계 대상 — 정부기관 또는 내외국인
    • ④ 합리성 — 최고선택 vs 차선선택
    • ⑤ 연속적 결정 — 여러 이해관계가 뒤섞인 동적 과정
  • vs 의사결정 핵심 차이 — 정책결정: 연속적 과정 / 의사결정: 원칙상 한 번의 선택
  • 유형 3쌍
    • 정형적 vs 비정형적 (반복·선례 유무)
    • 전략적("무엇") vs 전술적("어떻게")
    • 개인적 vs 집단적 (장단점 명확)
정책결정 변수와 기준
변수 3가지규범적·현실적 기준
▶
  • 변수 3가지
    • ① 환경 — 사회·정치·경제 상황, 이익집단·NGO 역할
    • ② 정책결정자 (권위주의 행정에서 핵심) — 개성·가치관·자원
    • ③ 정책결정구조 — 조직의 구조·절차·관례
  • 규범적·당위적 기준
    • ① 공익 — 정신적 자세의 기초
    • ② 정책철학(뿌리) — 목적달성에 바람직한 가치들의 총체
    • ③ 정책이념(나무) — 능률성·효과성·합법성·민주성 등 최고가치
  • 현실적·경험적 기준
    • ① 가치 — 정치적 기반집단·조직·사회 윤리
    • ② 유권자·이익집단
    • ③ 여론
    • ④ 결정규칙·선례·관행
정책결정과정 7단계
Ⅲ종 과오Thompson 4전략소망성·실현가능성
▶
  • ① 문제 파악과 정의 — Ⅲ종 과오: 해결 대상 자체를 잘못 선택 → 전체 방향 오류, 프레이밍 효과 주의
  • ② 목표 설정 — 능률성 기준 우선순위 / 적합성(올바른 목표?) + 적절성(적당한 수준?)
  • ③ 정보수집과 분석
  • ④ 대안 탐색과 개발 ★핵심
    • 탐색 원천: 경험·이론·주관적 방법·이해관계집단
    • 실현가능성(정치적·행정적·경제적·기술적) 검토
    • 지배의 원리: 열등한 대안 제외
  • ⑤ 결과예측 — 비분석적·모형·정책실험·직관적 방법
  • ⑥ 비교·평가
    • 소망성: 효과성 + 능률성 + 형평성
    • 실현가능성: 기술적·재정적·행정적·법적·윤리적·정치적
  • ⑦ 대안 선택 — Thompson 4전략
    • 계산전략: 합리적 분석으로 최적대안 (수리화 가능 분야)
    • 판단전략: 전문가 판단에 의존
    • 타협전략: 이해관계자 협상
    • 영감전략: 직감에 의존 (비교 불가한 경우)
정책분석과정
합리적 분석순환적 과정
▶
  • 정책분석 — 합리적·체계적 접근, 정보를 창출·조직·제공
  • 절차 — 반복적·순환적·연쇄적 (문제분석 → 목표설정 → 대안탐색 → 예측 → 평가 → 선택 → 다시 문제분석)
  • 핵심 과정 — 정책대안의 탐색과 개발
  • 정책결정 vs 정책분석
    • 결정: 정치적 요인 포함한 실제 채택 여부 결정
    • 분석: 가장 효율적·합리적 대안 선택 (분석결과 기초)
    • 둘은 완전히 분리되지 않고 겹쳐 움직임

정책집행
정책지침을 실행으로 옮기는 과정
▶
정책집행 개념과 특징
상호적응적 집행SOP5단계
▶
  • 전통적 정의 — 주어진 정책 목표 달성을 위해 행동
  • 현대적 정의 — 이해집단과 집행자가 상호작용하는 과정
  • 잘못된 견해
    • 정책 만능주의: 법 제정만 하면 해결된다는 착각
    • 정책목표 고정: 집행 중 재해석 가능성 무시
    • 집행자 = 단순 전달자 (계층적 조직관)
  • 상호적응적 집행
    • 조직적 적응: SOP가 목표 달성 위해 변화
    • 프로그램 적응: 집행환경 특수성에 맞게 정책 조정
  • 집행 5단계 — 정책지침 작성 → 자원 확보 → 조직화 → 실현활동 → 감독·통제
  • 4가지 특징 — 정책의도 실현 / 구체적·지속적 결정 / 국민생활 직결 / 정책형성·평가와 상호작용
정책순응 — 의의와 원인
순응 vs 수용원인 7가지
▶
  • 순응(compliance) — 외면적 행동 측면에서 저항하지 않음 (행태 차원)
  • 수용(acceptance) — 외면적 행동 + 내면적 가치까지 따름 (더 깊은 개념)
  • 순응이 확보돼도 정책수단이 잘못되면 정책실패 가능
  • 순응의 원인 7가지
    • ① 권위 — 정통성 인정·존경
    • ② 합리성 — 정책이 필수불가결하다는 판단
    • ③ 정부의 정통성 — 행정절차 정당성
    • ④ 개인적 이익 (가장 빈번) — 이익을 보는 사람들이 협조
    • ⑤ 제재의 사용 (가장 불안정) — 벌금·구속 회피
    • ⑥ 평판 — 사회윤리적 신용·명예 중시
    • ⑦ 지속 시간 — 장기 집행 → 습관화 → 순응 증가
불응과 순응 확보 전략
불응 원인·형태6가지 전략
▶
  • 불응의 원인 → 형태
    • 행동부담 회피 → 지연
    • 정책에 대한 불만 → 임의변경
    • 정통성·권위 결여 → 형식적 순응
    • 자원의 부족 → 부집행
    • 의사전달 미흡 → 고의적 조작
  • 순응 확보 6가지 전략 (강제성 약 → 강)
    • ① 설득 — 이성적 설명, 공청회·토론회
    • ② 선전 — 정책 내용 홍보
    • ③ 유인·보상 — 물질적·정신적 혜택으로 자발적 순응
    • ④ 처벌·제재 (불가피한 경우만) — 비자발적 순응
    • ⑤ 동의·지지 획득 — 순응자에게 실질적 편익
    • ⑥ 정책내용 변경·수정 — 불응 원인 자체를 제거
정책집행 영향요인
내적·외적 요인대상집단 조직화
▶
  • 내적요인 — 목표의 명확성·일관성 / 의사소통 효율성 / 집행책임자 리더십 / SOP / 예산·인력·정보
  • 외적요인 — 환경 변화 / 대상집단 태도·정치력 / 여론 / 정책결정기관 지원 / 기술
  • 대상집단 조직화와 집행 용이성
    • 수혜집단: 조직화 강약 관계없이 집행 용이
    • 희생집단 조직화 강 → 집행 곤란
    • 희생집단 조직화 약 → 집행 용이
    • 가장 어려운 경우: 희생집단이 강하게 조직화 + 수혜집단보다 크거나 같을 때
13주
정책평가
절차 타당성 + 결과 효과성 검토
▶
정책평가 개념과 목표
보건의료정책동태적·순환적
▶
  • 보건의료정책 — 국민건강 보호·증진을 위해 정부기관이 공식 결정한 기본방침
  • 절차적 측면 — 수립·집행 과정이 공식적·타당한 절차를 거쳤는지
  • 결과적 측면 — 결과가 국민건강 보호·증진에 효과적이었는지
  • 목표 — 보건의료정책 개선 + 현행·미래 정책의 안내자 역할
  • 정책평가 = 정책순환의 마지막 고리 + 다음 순환의 출발점
정책평가의 유형
3가지 분류 기준
▶
  • ① 평가목적 기준
    • 과정평가: 정책결정·집행 과정 평가 (개선·환류 목적)
    • 영향평가: 집행 후 산출·영향 평가 (효과 검증·책임성)
  • ② 평가단계(시기) 기준
    • 사전평가: 집행 전 = 정책분석
    • 과정평가: 집행 중 문제점 해결
    • 사후평가 (일반적 "정책평가"): 집행 후 최종 / 순수효과 추정 / 환류(Feedback)가 목적
  • ③ 평가자 위치 기준
    • 내부평가: 자체평가 + 상부평가
    • 외부평가: 집행체제 밖 전문가
    • 선택 기준 없음 — 정책 성격·의뢰자 가치체계에 따라
정책평가 절차 6단계
논리모형이해관계자환류
▶
  • 1단계 — 평가 목적과 결과 정의 (논리모형: 투입→실적→결과→영향)
  • 2단계 — 이해관계자 확인 + 요구 파악
  • 3단계 — 목적과 질문 도출 ("무엇이 달라지는가" vs "어떻게 수행되는가")
  • 4단계 — 평가방법 선정
  • 5단계 — 자료 확보 및 평가 수행
  • 6단계 — 평가결과 확산 (환류) — 전달 대상도 초기에 결정
평가기준 — 집행자 관점
능률성효과성적정성형평성
▶
  • 능률성(Efficiency) — 산출/투입 비율. 최소비용 최대효과 (사회적 능률 강조 추세)
  • 효과성(Effectiveness) — 정책목표 달성 정도. 정책성공 판단의 제1기준
    • 측정 저해요인: 비용 비고려 / 목표 애매·상충 / 수단 충실해도 목표 미달
  • 능률성·효과성 = 집행자 관점 → 소비자 입장에서는 의미 없는 기준으로 인정되는 경향
  • 적정성(Adequacy) — 문제를 어느 정도 해결했는가 (사회적 충분성)
    • 평가 객관성에 한계 — 기준이 주체에 따라 달라짐
  • 형평성(Equity) — 정책효과·편익이 공정하게 배분됐는지
    • 균형(체제 간 가치 배분) + 평등(법 앞의 균등한 기회)
평가기준 — 수혜자 관점
대응성만족도민주성참여성
▶
  • 대응성(Responsiveness) — 수혜자의 요구·기대에 융통성 있게 대처하는 능력
    • 공식 목표달성도 ↑ ≠ 수혜자 만족도 ↑
    • 수혜집단: 직접 효과를 받는 수혜자(시민)
  • 만족도(Satisfaction) — 정책 최종 성패 판단기준
    • 대응성보다 넓음: 직접수혜자 + 일반 시민 + 이해관계자 모두
  • 민주성(Democracy) — 국민 참여 확대 + 여론 충실 반영
  • 참여성(Participation) — 결정·수행·평가 과정에 다수 국민 참여
    • 참여 정도에 따라 보건의료서비스의 질이 좌우됨
    • 현대 복지국가 가장 기본적 평가기준 — 정책 정당성 확보 핵심
